# OSS publication roadmap

This is an outcome roadmap, not a claim that every feature is accepted.
The first public release is **Developer Preview** for one owner, one same-origin
Hermes installation and one foreground conversation. The existing R01–R22 source
remains; paid generation, physical devices and opt-in features have separate gates.

| ID | Milestone | Dependencies | Exit criterion |
| --- | --- | --- | --- |
| O01 | Observe and isolate the actual source/runtime | none | Preserve dirty work and the installed release; dedicated branch |
| O02 | Review disclosure and licenses | O01 | Reviewed public allowlist; redacted secret/metadata scan; material provenance |
| O03 | Correct JA/EN documentation | O01 | README, privacy, security and contribution rules agree with active code |
| O04 | Portable static operations | O01 | Read-only doctor; default dry-run; actual old backup; collision/drift rejection and rollback tests |
| O05 | Setup and sanitized diagnostics | O01 | Existing handshake projected into guidance; explicit allowlisted report; zero writes |
| O06 | Reproducible public packages | O02–O05 | Clean exported source builds; source/static checksums; fixed backend relationship |
| O07 | Final verification | O06 | Type/lint/full unit/build/static, both fixture browsers and update/rollback; exact-source CI |
| O08 | Publish Developer Preview | O07 | Authorized target; immutable reviewed source/tag; notices and checksummed assets |
| O09 | Verify public retrieval | O08 | Anonymous repository/Release retrieval and isolated install checks |

Private operational receipts are maintained outside the public source package.
Do not rewrite history, remove existing worktrees or publish unresolved personal
operations metadata to make this roadmap appear complete.

## Developer Preview scope

- Existing Dashboard authentication, same-origin HTTPS/WSS and fresh tickets.
- Registered profile/project/session navigation; real server requests; memory drafts.
- Quotes, loaded-body search, expanded editor, templates and explicit Markdown export.
- JPEG/PNG or supported document selection and details. Selecting never transfers.
- Capability-gated attachment turns, canonical artifacts/files and session models.
- Opt-in encrypted drafts/history, static worker, notifications and device speech.
- iOS source is experimental and uncompiled unless separately verified.

Code, unit, synthetic-provider Gateway, deployment, real generation, device and
user consent are distinct statuses. Unsupported capabilities remain disabled.

## Beta gate, after source publication

Resolve the documented development-only braces/mocker advisories when compatible
patched versions are available; retain an isolated trusted-input build/test boundary.
No critical/runtime npm finding is knowingly accepted as a normal installation.

1. Real Web text send, answer and stored-history resume on an explicitly permitted
   isolated profile/provider with bounded output and zero automatic retry.
2. Safari and Home Screen tested separately: native input/IME, keyboard, orientation,
   200% text and modal focus/draft/scroll recovery.
3. Accepted running turn before 30-second/5-minute lock; authoritative result/state
   after return. Do not force long generation to fill the interval.
4. Approval/clarify/cancel, stop, attachments, model writes, OS saving and consented
   storage/notifications/speech each require their own real acceptance.

The historical personal text-test budget is not a product default or public test
authorization. Do not contact a provider or enable tools as part of installation.
